# finance/private/

Everything personal lives here: `profile.yaml`, tax-input JSON files, uploaded statements, and
reports in `reports/`. Git ignores this whole folder except this README, and a hook blocks
commits that would include it, because the repository is public.

Cloud sessions start from a fresh clone, so these files do not carry over to the next session.
The advisor offers to back them up to a `CA Advisor` folder in your Google Drive and to restore
them from there.
