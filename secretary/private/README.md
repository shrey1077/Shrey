# secretary/private/

Donna's working files live here: `preferences.yaml`, `tasks.md`, `people.md`, and briefs, meeting
notes and trip plans in `notes/`. Git ignores this whole folder except this README, and a hook
blocks commits that would include it, because the repository is public.

Cloud sessions start from a fresh clone, so these files do not carry over to the next session.
Donna offers to back them up to a `Donna` folder in your Google Drive and to restore them from
there.
